# Diego Maximo — Portfólio

Portfólio single-page feito com React + TypeScript + Tailwind CSS + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
```

## Onde editar seu conteúdo

Abra:

`src/data/content.ts`

Ali estão:
- dados pessoais
- redes sociais
- experiências
- projetos
- educação
- ferramentas
- contato
- estatísticas

## Foto e CV

Coloque na pasta `public/`:

- `profile.jpg`
- `Diego-Maximo-CV.pdf`

## Publicação

O projeto pode ser publicado gratuitamente na Vercel conectado ao GitHub.
